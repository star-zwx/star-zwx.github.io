# 如何修改你的个人主页

## 1. 先认识需要修改的文件

网站的大部分内容都在根目录的 **`site.config.js`**，用 VS Code 或其他文本编辑器打开即可。

| 想修改什么 | 修改位置 |
| --- | --- |
| 姓名、学校、邮箱、头像、简历 | `profile` |
| 大标题、自我介绍、近期动态 | `about` |
| 研究方向 | `research` |
| 论文、作者、会议、链接、引用 | `publications` |
| 教育、实习、科研经历 | `experience` |
| 页末联系文字 | `contact` |
| 页脚更新日期 | `footer.updated` |
| 主题颜色、字体、大小、间距 | `styles.css` |
| 导航和栏目的固定标题 | `index.html` |

文件保存为 **UTF-8**。本地修改后刷新浏览器，线上修改后需要提交并推送到 GitHub，等待自动部署完成。

## 2. 修改姓名和联系方式

找到 `profile`，按下面的方式替换值，不要删除字段名称、引号或项目间的逗号：

```javascript
profile: {
  name: "Xiaoming Zhang",
  nativeName: "张小明",
  initials: "XZ",
  role: "Ph.D. Student",
  department: "Department of Computer Science",
  affiliation: "你的大学名称",
  location: "Shanghai, China",
  email: "xiaoming@university.edu",
  avatar: "assets/avatar.jpg",
  cv: "assets/cv.pdf",
  note: "Open to research collaborations.",
  links: [
    { label: "Email", icon: "mail", href: "mailto:xiaoming@university.edu" },
    { label: "Google Scholar", icon: "scholar", href: "https://scholar.google.com/citations?user=你的ID" },
    { label: "GitHub", icon: "github", href: "https://github.com/你的用户名" },
  ],
},
```

**邮箱有两处要改：** `email` 控制正文和页末联系按钮，`links` 中的 `mailto:` 控制左侧 Email 链接。

- `nativeName: ""` 隐藏中文名。
- `note: ""` 隐藏左侧说明。
- `cv: ""` 隐藏简历按钮，上传真实 PDF 后再填写文件路径。
- 不需要的社交链接，直接删除相应的 `{ ... },` 整行。
- 社交图标可用 `mail`、`scholar`、`github`、`external`。
- 当前默认 Google Scholar / GitHub 指向平台首页，发布前改为你自己的资料页。

### 放入头像与简历

1. 把头像复制到 `assets/` 文件夹，重命名为 `avatar.jpg`。
2. 把希望公开的简历放在同一文件夹，重命名为 `cv.pdf`。
3. 对应填写 `avatar: "assets/avatar.jpg"` 和 `cv: "assets/cv.pdf"`。

建议头像使用接近正方形的图片，至少 500 × 500 像素。不要直接填写 `D:\照片\头像.jpg` 这样的电脑路径，线上无法访问。文件名大小写必须一致：GitHub 服务器区分 `Avatar.jpg` 和 `avatar.jpg`。

`assets/` 中的文件会被部署并可以公开访问，只放计划公开的文件。简历只使用你自己提供的真实 PDF，项目不包含虚构简历。

## 3. 修改个人介绍与动态

```javascript
about: {
  title: "Exploring intelligence.\nBuilding for people.",
  paragraphs: [
    "第一段个人介绍，可以填写你的学校、专业、导师和目前的研究课题。",
    "第二段可以介绍你感兴趣的问题、研究目标或个人爱好。",
  ],
  news: [
    { date: "2026.11", text: "我开始了一个新的研究项目。" },
    { date: "2026.09", text: "我的论文被某会议接收。" },
  ],
},
```

- `\n` 让大标题换行，第一行之后使用绿色斜体。
- `paragraphs` 每一项对应一个段落。
- `news` 按填写的顺序显示，建议把最新动态放最上面。
- 暂无动态时填 `news: []`，整个 Lately 区块会自动隐藏。
- 内容按纯文本处理，不需要也不支持插入 HTML 标签。

## 4. 修改研究方向

```javascript
research: {
  intro: "我关注的几个研究方向。",
  items: [
    { icon: "network", title: "机器学习", description: "研究能够从复杂数据中学习有效表示的算法。" },
    { icon: "human", title: "人机交互", description: "设计更易于理解、更有帮助的智能系统。" },
    { icon: "science", title: "开放科学", description: "推动可复现、可共享的研究实践。" },
  ],
},
```

内置图标：`network`、`human`、`science`，也可使用社交图标。推荐展示 2–3 个方向。`items: []` 会同时隐藏研究栏目及对应导航。

## 5. 添加、修改论文

`publications.items` 中每个 `{ ... }` 是一篇论文。复制现有论文结构，修改为你的真实成果：

```javascript
{
  id: "zhang-2026-my-paper",
  year: 2026,
  title: "你的真实论文标题",
  authors: ["Xiaoming Zhang*", "Another Author*", "Advisor Name"],
  venue: "会议或期刊完整名称",
  venueShort: "CONF 2026",
  summary: "用一两句话概述研究内容或主要发现。",
  illustration: "network",
  image: "assets/my-paper.png",
  links: [
    { label: "Paper", href: "https://你的论文实际地址" },
    { label: "Code", href: "https://github.com/你的用户名/代码仓库" },
    { label: "Project", href: "https://你的项目实际地址" },
  ],
  bibtex: `@inproceedings{zhang2026paper,
    title={你的真实论文标题},
    author={Zhang, Xiaoming and Other, Author},
    booktitle={实际会议名称},
    year={2026}
  }`,
},
```

上面的地址和引用只是格式示范，请用论文真实信息替换。

| 字段 | 说明 |
| --- | --- |
| `id` | 每篇论文唯一，推荐英文小写和连字符 |
| `year` | 数字，不加引号；用于自动排序和年份筛选 |
| `authors` | 作者姓名数组；与 `profile.name` 相同的姓名自动突出显示，支持末尾 `*` |
| `venueShort` | 会议或期刊缩写标签，不需要可填 `""` |
| `summary` | 简短说明，不需要可填 `""` |
| `illustration` | 内置示意图：`network`、`layers`、`dots` |
| `image` | 自己的论文缩略图路径，`""` 表示使用内置示意图 |
| `links` | 真实论文、代码和项目链接；没有就填 `[]`，不会出现无效按钮 |
| `bibtex` | 多行引用用反引号包围，填写后才会显示 Cite 按钮；`""` 表示隐藏 |

默认的抽象图形只是装饰示意图，不是实验结果图。你可以替换成真实方法图或结果图，推荐横向图片。**默认的三篇论文都是示例，没有真实论文链接和引用，发布前必须替换或删除。**

如果还没有发表论文，使用：

```javascript
publications: {
  note: "Research in progress.",
  items: [],
},
```

栏目会显示一句简洁的待更新提示。若要整个删除该栏目，可在 `index.html` 中同时删除对应导航链接和 `id="publications"` 的 section，并相应调整 `app.js` 的渲染代码；通常保留空状态即可。

## 6. 修改教育与研究经历

```javascript
experience: [
  {
    period: "2026 — Present",
    title: "Ph.D. in Computer Science",
    institution: "你的学校",
    detail: "导师、研究方向或其他简短说明。",
    current: true,
  },
  {
    period: "2022 — 2026",
    title: "B.Sc. in Computer Science",
    institution: "你的本科学校",
    detail: "",
  },
],
```

按你填写的顺序显示，建议逆时间排列。`current: true` 将该经历的时间线圆点标绿。`experience: []` 会隐藏整个栏目和对应导航。

## 7. 修改联系文字与更新日期

```javascript
contact: "欢迎就研究合作、学术交流与我联系。",
footer: {
  updated: "November 2026",
},
```

版权年份自动使用访问时的当前年份；`updated` 需要在修改资料后手动更新，填 `""` 可隐藏更新日期。

## 8. 把页面改成中文

1. 直接把 `site.config.js` 中的姓名、介绍、论文说明等换成中文。
2. 将 `index.html` 的 `<html lang="en">` 改为 `<html lang="zh-CN">`。
3. 修改 `index.html` 的固定栏目名，例如 About → 关于我，Research → 研究方向，Selected publications → 代表论文。
4. 需要完整中文交互时，把 `app.js` 中的 `All`（同时修改相关判断）、`Cite`、复制提示、空状态提示等一并替换。

当前字体已经包含中文系统字体后备，不需要下载字体。

## 9. 修改颜色和布局

打开 `styles.css`，最上面的变量控制主题：

```css
:root {
  --paper: #f8f9f6; /* 页面背景 */
  --ink: #29362e;   /* 主要文字 */
  --muted: #65705f; /* 次要文字 */
  --green: #365c46; /* 链接与主题色 */
  --line: #dfe4da;  /* 分隔线 */
}
```

调整 `--serif` 更换标题字体，`--sans` 更换正文字体。页面已经提供平板和手机断点，修改布局后应一起检查窄屏显示。

## 10. 每次修改后做一次检查

```powershell
cd D:\selfWEB
npm run check
npm run dev
```

看到 `Checks passed` 说明语法、主要字段和本地资源检查通过。然后在浏览器确认布局、头像、论文年份切换和联系方式。

常见问题：

- **页面内容全部消失**：通常是配置漏写逗号或引号。运行 `npm run check` 查看报错位置。
- **引号出错**：使用英文半角引号，避免输入法把 `"` 替换成 `“`。字符串内部的双引号写成 `\"`，或者用单引号包围整段。
- **头像没显示**：核对文件是否放在 `assets/`，路径、后缀与大小写是否完全一致。
- **本地正常，GitHub 图片失效**：使用 `assets/avatar.jpg`，不要写 `/assets/avatar.jpg` 或本机绝对路径。
- **修改后没生效**：本地刷新；线上先确认 GitHub Actions 已成功，再用 `Ctrl+F5` 强制刷新。
- **Cite 按钮没出现**：只有论文 `bibtex` 不是空字符串时才显示。
- **点击复制没有自动复制**：浏览器可能限制剪贴板权限，按提示手动 `Ctrl+C` 即可。
- **示例内容提示**：检查脚本会提醒默认姓名，但不会判断所有示例是否已替换。请自行核对真实资料。
